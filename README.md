# Melsoft Campus Manager


A console-based Python application for managing courses, students, enrolments, marks, transcripts, and academy reports. Built as the Python Essentials 1 Capstone Group Project using dictionaries, functions, validation, and Git collaboration.


## Features
- Add a course
- Register a student
- Enrol a student in a course
- Record a mark
- View a student transcript
- Generate a course report
- Search students and courses
- Withdraw a student from a course
- Generate an academy report

## How to Run
Open the project folder in VS Code and run:

```bash
python3 campus.py
```

## Workflow

This project follows a Git branching workflow.

- The project skeleton is committed to the `main` branch.
- Each workstream is developed on its own feature branch.
- All code is tested before being committed.
- Every completed feature is merged into `main` through a Pull Request after review.
